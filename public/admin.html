Admin Sign In
First-time setup grant admin access to your email
1. In Supabase SQL Editor, run (replace with YOUR email registered in Auth):
insert into public.admin_users (user_id, email) select id, email from auth.users where lower(email) = lower('you@gmail.com') on conflict (user_id) do nothing;
2. Then sign in above with that email + password.
Only emails in admin_users get admin access.

Then run supabase/admin-dashboard.sql if you haven't yet (creates the dashboard RPCs). If a function is reported missing, reload schema cache: Supabase Settings API Reload schema cache.
Sign in with Admin Key instead
The key must already be saved to the database (set once via SQL).
